可视化能力

常用操作，都有清晰界面

把 Grok CLI 的能力整理为可点击、可查看、可恢复的桌面工作流。

打开即用的 CLI 面板

打开面板 → 选择项目 → 开始对话 → 查看结果
对话过程

过程清晰可见

回复、思考、工具与计划实时呈现，生成中也能随时停止。

会话中心

历史会话随时恢复

按项目浏览本机会话，查看摘要并继续之前的任务，不用翻找命令记录。

模型 · 项目

模型与项目一键选择

图片

权限

权限可视化确认

工具调用通过弹窗批准或拒绝，也可为信任场景开启自动批准。

设置中心

一个页面管好所有选项

语言、主题、托盘、通知、更新与 CLI 选项集中管理；需要时可在应用内检查和安装 CLI。

工作原理

你操作面板，CLI 在后台工作

Grok Desktop 不另造模型服务，只把官方 Grok CLI 变成桌面 GUI；日常使用不需要输入命令。

01 · PANEL

可视化面板

点选 · 输入 · 拖放

会话、模型、项目、图片与权限都在原生窗口中操作，日常无需打开终端。

02 · BRIDGE

后台连接

ACP · JSON-RPC

面板在后台把操作交给 CLI，并把回复、进度和工具结果实时带回界面。

03 · ENGINE

官方 Grok CLI

登录 · 模型 · 工具

本机 Grok CLI 负责登录态、模型和工具能力；项目不托管你的密钥或另接聊天接口。

产品界面

每项能力，都有可操作界面

从会话中心到模型选择、消息时间线与设置，常用操作无需在终端和配置文件之间切换。

窗口布局

从选择到发送，全程在窗口里

清楚分区、明确信息层级，并提供深色与浅色主题，长时间使用也容易找到当前状态。

  • 侧栏：新建对话、浏览历史与查看连接状态
  • 顶栏：切换模型、项目目录与会话状态
  • 输入区：添加图片、发送消息与随时停止

会话中心

按项目整理历史，快速新建、预览和恢复会话。

模型与项目

用下拉菜单选择模型和工作目录，当前上下文始终可见。

设置中心

集中管理语言、主题、通知、更新、权限与 CLI 状态。
