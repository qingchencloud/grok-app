Grok Desktop — unofficial GUI for the official Grok Build CLI
================================================================

Official release downloads:
  https://github.com/qingchencloud/grok-app/releases

  ★ GrokDesktop-Setup-*-windows-x64.exe
      Real installer (recommended):
      - Installs to %LOCALAPPDATA%\Programs\Grok Desktop\
      - Start Menu shortcut
      - Desktop shortcut
      - Uninstall via Windows Settings → Apps

  · GrokDesktop-*-windows-x64.exe
      Portable single file (no install, no shortcuts)

After install, install/login the Grok CLI if needed:
  irm https://x.ai/cli/install.ps1 | iex
  grok login
